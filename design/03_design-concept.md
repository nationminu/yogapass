## 2. 시안

### 2.0 3안 공통 사항 (읽고 나서 개별 시안을 보십시오)

**① 대비 측정 방법.** 아래 모든 대비값은 designer가 **WCAG 2.1 상대 휘도 공식**(sRGB → 선형화 → `0.2126R+0.7152G+0.0722B`, 대비 = `(L1+0.05)/(L2+0.05)`)으로 직접 계산했다. 별도 표기가 없으면 **흰 배경 `#FFFFFF` 기준**이며 소수 둘째 자리에서 반올림했다. P5에서 자동 검사 도구로 재측정하면 같은 값이 나와야 한다.

**② 상태 4색은 3안 공통값을 쓴다.** 브랜드 블루만 시안별로 다르고, 성공·경고·오류·마감 색은 같은 값을 공유한다. 이유는 두 가지다 — ⓐ 대비 검증 비용을 한 번만 치른다 ⓑ 어느 시안이 선택되어도 2차 상태 배지 20종 이상을 그대로 재사용한다.

| 역할 | HEX | 배경 | 대비 | 용도 | 색 외 구분 수단 |
|---|---|---|---|---|---|
| 성공·잔여 | `#1B6E3C` | `#FFFFFF` | **6.28:1** | 잔여 n, 예약 완료 | 텍스트 라벨 "잔여 n" |
| 성공 배경 | `#E7F4EC` | — | (`#1B6E3C` 올릴 때 **5.55:1**) | 예약 가능 셀 | 테두리 `#9FCBB1` |
| 마감·비활성 | `#4F5B6B` | `#FFFFFF` | **6.90:1** | 마감, 지난 날짜 | 라벨 "마감" + **사선 해치 + 취소선** |
| 마감 배경 | `#EEF1F5` | — | (`#4F5B6B` 올릴 때 **6.09:1**) | 마감 셀 | 사선 해치 패턴 |
| 경고 | `#8A5200` | `#FFFFFF` | **6.39:1** | 취소 마감 임박, 중복 안내 | 아이콘 + 라벨 |
| 오류 | `#B3261E` | `#FFFFFF` | **6.54:1** | 폼 오류, 정원 소진 | 아이콘 + `role="alert"` + 오류 요약 블록 |
| 입력 테두리·UI 경계 | `#7E8FA3` | `#FFFFFF` | **3.31:1** | 입력 필드, 보조 버튼 테두리 | WCAG 1.4.11 (3:1) 충족 |

**③ 폰트는 3안 모두 무료·상업적 사용 가능 폰트만 쓴다.** 상세는 `design/assets/SOURCES.md` §2. 목업은 **웹폰트를 로드하지 않으므로**(외부 의존 0) 실제 조판과 자간·두께가 다르게 보일 수 있다. 실제 폰트는 P4에서 self-host 한다.

**④ 목업의 모든 값은 예시다.** 날짜·강사·잔여 수·시간·주소·전화는 실제 값이 아니며 `[TBD]`로 표시하거나 "예시"라고 적어 두었다. 고객 확인 전 값을 실제처럼 보이게 하지 않았다.

### 3.2 디자인팀 권고안

**권고: 시안 A — 정돈된 신뢰.**

근거 (우선순위 순):

1. **이 프로젝트의 진짜 무게중심은 2차다.** 1차 6화면 : 2차 39화면이다. 컨셉은 6화면이 아니라 45화면을 견뎌야 하고, 2차 화면의 대부분은 **캘린더·표·폼·배지**다. A는 토큰 1벌로 이 전부를 덮는 유일한 안이다.
2. **고객 요청 문구에 가장 정확하다.** "화이트·블루로 신뢰감 있게" + PM 보강 "밝고 정돈된, 무겁지 않게" → 흰 면적이 가장 크고 블루를 행동에만 쓰는 A가 문자 그대로 부합한다. C는 "밝음"보다 "대비"가, B는 "정돈"보다 "편안"이 앞선다.
3. **브랜드 자산 미확보 리스크에 가장 강하다**(RSK-010). 로고 원본·브랜드 컬러가 09-17 이후에 들어와도 A는 **Primary 1값 교체**로 전 화면이 따라온다. B(명조 + 곡률)와 C(네이비 색면)는 고객 로고와 충돌할 여지가 더 크다.
4. **일정에 가장 유리하다.** 1차 오픈 2026-11-06 기준으로 A가 기준선이고 B는 +2~3작업일이다. PM 방침이 "최대한 빨리"이므로 이 차이는 무시할 수 없다.
5. **접근성 위험이 0이다.** A의 팔레트에는 대비 미달 색이 하나도 없다. C는 `#4DA3FF` 사용 범위 규칙이 한 번만 깨져도 P5 결함이 된다.

**동시에 권고하는 보정 2가지** (A를 고르되 B의 장점을 흡수한다. 추가 공수 0~0.25작업일):

| # | 보정 | 이유 |
|---|---|---|
| A-보정-1 | **히어로·섹션 여백을 B 수준으로 올린다** (섹션 간격 88 → 96px, 히어로 상하 패딩 88 → 104px, `≥1280px` 한정) | A의 유일한 약점인 "담백함"을 여백으로 해소한다. 데이터 화면에는 적용하지 않으므로 밀도 손해가 없다 |
| A-보정-2 | **1차 소개형 화면에 한해 radius 8 → 12px, 강점 카드 아이콘을 원형으로** | 요가 업종의 부드러움을 최소 비용으로 얹는다. 캘린더·표·관리자에는 8px를 유지해 밀도를 지킨다 |

**권고하지 않는 조합**: B를 고르고 2차에서 관리자만 A로 전환하는 방식. 토큰 2벌 + 전환 경계 정의 비용이 붙어 총량이 가장 커진다(+4~6작업일).
