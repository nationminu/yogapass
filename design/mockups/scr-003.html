전화 문의
↑ 세 번째 프레임 하단이 고정 바 S2 "전폭 1버튼"(대표 전화 확정 후의 이 화면 상태)이다.
이 목업에서 확인할 것
  • 지도 클릭 투 로드 — 대체 영역과 로드 후 iframe의 높이가 같다(360px 272px · 768~1279px 320px · 1280px 400px). 초기 로드에서 지도 도메인 요청 0건(REQ-F-032). 대체 영역은 CSS 그래픽이며 지도 화면 캡처가 아니다(REQ-N-024).
  • 입력 font-size 16px — iOS Safari가 16px 미만 입력에 포커스하면 뷰포트를 자동 확대해 G-9(가상 키보드 중 고정 바 유지) 검증이 깨진다.
  • 필수 표시 3중 — *(색) + "(필수)" 텍스트 + required 속성. 색만으로 전달하지 않는다.
  • 오류 요약 블록 — REQ-N-008은 "입력 5개 이상"을 요구하지만 4항목인 이 폼에도 적용했다. 비용이 거의 없고 2차 8~10항목 폼에 그대로 재사용된다.
  • honeypot — 목업에는 보이지 않는다. 구현 시 display:none이 아니라 화면 밖 배치 + tabindex="-1" + aria-hidden로 만든다(REQ-N-019).
  • 고정 바 3상태 — S3(현재·미노출) / S2(전화 확정 후·전폭 1버튼) / S1(2차·2분할 복귀, TR-06). 개발은 전화번호 데이터 유무 + 현재 URL과 목적지 URL 비교로 분기하며 화면 목록을 하드코딩하지 않는다(G-7).
  • 제출 버튼과 고정 바 간격(G-4) — 바가 노출되는 상태에서 문서 끝까지 스크롤했을 때 16px 이상. 토큰은 --body-pad-bottom = 60px + safe-area + 16px.
