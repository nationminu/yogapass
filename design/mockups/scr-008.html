SCR-008 404 · SCR-009 공용 오류 화면 — 1차 페이지 목업

명세 design/03_page-design.md §6·§7 · 토큰 design/03_design-system.md §1.6. 외부 의존 0.
· SCR-009는 SCR-008 템플릿 재사용이며 문구·상단 심볼만 교체한다. 별도 레이아웃을 만들지 않는다.
· SCR-008은 반드시 HTTP 404(소프트 404 금지), SCR-009는 원인에 맞는 5xx·503을 반환한다. 둘 다 noindex이며 robots.txt에서 Disallow하지 않는다.
· SCR-009는 DB 장애 상태에서도 렌더되어야 하므로 동적 데이터에 의존하지 않는다. 전화번호·상호는 빌드 시점 상수로 주입하고, 없으면 해당 블록을 뺀다. 스택 트레이스·내부 경로·버전을 출력하지 않는다.

이 목업에서 확인할 것
  • 템플릿 1개 · 문구 2벌 — SCR-009는 별도 레이아웃 없이 SCR-008을 재사용한다(REQ-F-065). 개발도 컴포넌트 하나에 문구 props만 다르게 준다.
  • "404" 대형 숫자는 장식이다(aria-hidden="true"). 같은 정보가 h1 문장에 이미 있다 — 디자인 시스템 §4.3의 판정 원칙 그대로.
  • 대비 — "404" 숫자는 #7E8FA3(3.31:1)로 장식 기준 3:1을 넘긴다. 경고 아이콘은 #8A5200(6.39:1).
  • 헤더·푸터 정상 노출 — 다른 화면으로 이동할 수 있어야 한다. 관리자 경로의 404는 2차에 관리자 셸 안에서 보여주고 공개 GNB를 노출하지 않는다(REQ-F-060).
  • 하단 고정 바 2분할 유지 — 보조 화면에도 표기한다(G-7). 자기 참조가 아니다.
