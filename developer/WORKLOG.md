  - R1 16건을 v0.2 해당 절과 대조했다. 16건 모두 해결됐다. Must #1은 A'-1/A'-2a/A'-2b 분리, ADR-001 결정 항목 2·3, Q24·Q25로 해결됐다. Must #2는 §4.2 평가 정정, 예상 오픈일 표, S-1~S-4, O-6으로 해결됐다. planner R1 #1과 분류 차이가 있었지만 A'-2a·A'-2b 세분과 대응 관계 주석으로 충돌 없이 정리됐음을 확인했다.

  - O-6 환산을 검증했다(부록 B-2). P3 7작업일에서 설계·선검토·디자인 리뷰 약 2.5일을 빼면 구현 가용은 약 4.5일이다. A'-1은 여유 1일, A'-2a는 0~0.5일이다. 남는 분량(P5·P2·P3)으로 계산하면 10-28~10-29는 맞다. 다만 서버 측 서비스 선정·계정 준비가 10-02까지 끝나야 한다는 조건이 붙는다. 계정 준비가 G3이면 통합 확인 1일이 P4에 남아 10-29~10-30이 된다 → Should. A'-2b는 10-30~11-03으로 환산했다 → Could.
  - 새 문제를 확인했다. (b) 이메일 안내의 제3자 주소 악용 경로가 빠져 있다(알림 중단과 도메인 평판 하락 우려). 10-22 운영 환경 준비에 메일 인증 레코드 적용이 없다. S-3 단계 오픈에서 폼 서비스와 API 사이 전환 비용, 데이터 연속성, G8과의 겹침이 드러나지 않는다. A'-1의 삭제 요청·스팸 정리 수행 주체가 비어 있다.
  - 이미 해결된 사항은 다시 문제 삼지 않았다. 게이트를 막을 오류가 없어 Must는 0건으로 판정했다.
