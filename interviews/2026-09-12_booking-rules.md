# 예약 규칙 — 시간 슬롯·운영 시간·캘린더

> **출처**: 2026-09-12 총괄 PM 지시.
> "예약은 2시간(조절 가능) 레슨 기준으로 하고 06:00~20:00(조절 가능)까지 점심시간을 제외하고 예약을 진행한다. 예약 가능 여부는 캘린더로 표시하여 예약 가능할 때만 예약되도록 한다."
>
> 이 문서는 [ITV-001](2026-09-12_customer-interview.md)의 "시간표에서 수업 선택" 서술을 **대체**한다. 정식 요구사항은 CR-001 승인 후 `planning/02_requirements.md`에 반영한다.

## 1. 예약 단위

| 항목 | 값 | 조절 |
|---|---|---|
| 레슨 길이 | **2시간** | 관리자 설정 (30분 단위) |
| 슬롯 간 휴식 | 없음 (연속 배치) | 관리자 설정 (0·10·15분) |
| 예약 가능 시간대 | **06:00 ~ 20:00** | 관리자 설정, 요일별 |
| 점심시간 | 예약 불가 구간으로 제외 — 시각 `[TBD: 고객 확인 필요]` | 관리자 설정 |

## 2. 슬롯 생성 규칙

1. 운영 시작 시각부터 레슨 길이 단위로 슬롯을 만든다.
2. 점심시간과 겹치는 슬롯은 만들지 않고, 점심시간이 끝난 시각부터 다시 시작한다.
3. 운영 종료 시각을 넘기는 슬롯은 만들지 않는다.

**예시** (06:00~20:00, 2시간, 점심 12:00~13:00)

| 오전 | 오후 |
|---|---|
| 06:00–08:00 | 13:00–15:00 |
| 08:00–10:00 | 15:00–17:00 |
| 10:00–12:00 | 17:00–19:00 |
| — | 19:00–20:00은 2시간을 채우지 못해 **생성하지 않음** |

→ 하루 6슬롯. 설정값이 바뀌면 슬롯 수도 자동으로 바뀐다.

## 3. 캘린더 표시

- 예약 페이지(SCR-004)는 **월간 캘린더**를 먼저 보여준다.
- 날짜마다 상태를 표시한다.

| 상태 | 표시 | 선택 |
|---|---|---|
| 예약 가능 | 잔여 슬롯 수 또는 "예약 가능" | 가능 |
| 마감 | "마감" | 불가 |
| 휴무 | "휴무" | 불가 |
| 예약 기간 밖 | 흐리게 | 불가 |

- 날짜를 고르면 그 날의 슬롯 목록이 열리고, 슬롯마다 시간·잔여 인원을 보여준다.
- **예약 가능한 슬롯만 선택할 수 있다.** 마감·지난 시간·휴무 슬롯은 선택 자체가 막힌다.
- 색상만으로 상태를 구분하지 않는다(접근성). 텍스트 라벨을 함께 둔다.

## 4. 예약 성립 조건

모두 충족해야 예약이 확정된다.

1. 로그인한 회원이다 (비회원 불가)
2. 슬롯 정원에 여유가 있다
3. 현재 시각 기준 최소 리드타임이 남아 있다 — `[TBD]` (예: 1시간 전까지)
4. 예약 오픈 범위 안이다 — `[TBD]` (예: 오늘부터 4주 이내)
5. 1인당 동시 예약 한도를 넘지 않는다 — `[TBD]`
6. 휴무일·점심시간이 아니다

> **동시 예약 처리**: 마지막 한 자리를 두 사람이 동시에 누르면 한 명만 성공해야 한다. 서버에서 정원을 확인·차감하는 처리가 필요하다(P4 기술 설계 항목).

## 6. 기존 문서와의 차이

| 항목 | ITV-001 (인터뷰) | 이 문서 (PM 지시) |
|---|---|---|
| 예약 대상 | 수업(클래스) 시간표에서 선택 | **시간 슬롯**에서 선택 |
| 운영 시간 | 평일 06:00~22:00 / 주말 09:00~18:00 | **06:00~20:00** (요일별 설정 가능) |
| 점심시간 | 언급 없음 | **예약 불가 구간** |
| 화면 | 시간표 목록 | **월간 캘린더 → 슬롯 목록** |

→ 상충하는 부분은 **이 문서가 우선**한다. 다만 주말 운영 시간은 확인이 필요하다.

## 7. 영향

### 공수 (1차 환산, developer 검토 전)
| 항목 | 추가 작업일 |
|---|---|
| 캘린더 UI (월 이동, 상태 표시, 접근성·모바일) | 1.5~2 |
| 슬롯 생성 로직 + 설정 반영 | 1~1.5 |
| 관리자 설정 화면 (운영 시간·점심·정원·휴무일) | 1~1.5 |
| 동시 예약 정원 처리 | 0.5~1 |
| **합계** | **+4~6** |

→ [ITV-002](2026-09-12_summary-and-options.md) 구현 추정 20~26 작업일이 **24~32 작업일**로 늘어난다. 단계 오픈 2차 일정이 **11월 말~12월 초**로 밀릴 수 있다.

### 삭제되는 요구
- 시간표를 정적 콘텐츠로 노출하는 방식 → 캘린더·슬롯으로 대체
- 희망 일시 자유 입력(T-28) → 슬롯 선택으로 대체
