# 예약 규칙 — 월별 스케줄 편성·게시와 캘린더 예약

> **출처**: 2026-09-12 총괄 PM 지시 (누적)
> 1. "예약은 레슨 기준으로 하고 06:00~20:00(조절 가능)까지 점심시간을 제외하고 예약을 진행한다. 예약 가능 여부는 캘린더로 표시하여 예약 가능할 때만 예약되도록 한다."
> 2. "레슨 길이는 60분으로 한다."
> 3. "슬롯은 관리자가 유연하게 열고 닫아 관리한다."
> 4. **"관리자는 월별 요가 스케줄을 설정하고 월 시간표(캘린더)를 게시하고, 해당 캘린더로 예약을 받는다. 앞서의 '예약 후 강사 배정'은 취소한다. 월별 일정에 슬롯과 강사를 배정한 뒤 게시하며, 월별 템플릿을 제공해 템플릿을 가져와 게시한다."**
>
> 이 문서는 [ITV-001](2026-09-12_customer-interview.md)의 "시간표에서 수업 선택"과, **v0.1의 "신청 → 관리자 강사 배정 → 확정" 흐름을 대체**한다. 정식 요구사항은 CR-001 승인 후 `planning/02_requirements.md`에 반영한다.

## 2. 후보 슬롯 생성 규칙

1. 운영 시작 시각부터 레슨 길이 단위로 슬롯을 만든다.
2. 점심시간과 겹치는 슬롯은 만들지 않고, 점심시간이 끝난 시각부터 다시 시작한다.
3. 운영 종료 시각을 넘기는 슬롯은 만들지 않는다.

**예시** (06:00~20:00, 60분, 점심 12:00~13:00)

| 오전 (6슬롯) | 오후 (7슬롯) |
|---|---|
| 06:00–07:00 | 13:00–14:00 |
| 07:00–08:00 | 14:00–15:00 |
| 08:00–09:00 | 15:00–16:00 |
| 09:00–10:00 | 16:00–17:00 |
| 10:00–11:00 | 17:00–18:00 |
| 11:00–12:00 | 18:00–19:00 |
| — | 19:00–20:00 |

→ 하루 최대 **13슬롯**. 이것은 **후보**일 뿐이며, 실제 운영 여부는 §3의 월별 스케줄 편성에서 정한다.

## 3. 월별 스케줄 편성과 게시 (핵심)

### 3.1 흐름

```
① 월 템플릿 불러오기  →  ② 월 스케줄 편집  →  ③ 검토  →  ④ 게시  →  ⑤ 회원 예약
   (주간 반복 패턴)       슬롯 열기/닫기        미리보기      공개        즉시 확정
                          강사 배정
                          정원 지정
```

1. **템플릿 불러오기** — 저장해 둔 월 템플릿을 선택하면 해당 월 전체에 주간 패턴이 펼쳐진다.
2. **편집** — 날짜별로 슬롯을 열고 닫고, 각 슬롯에 **강사를 배정**하고, 정원을 조정한다. 공휴일·행사일은 닫는다.
3. **검토** — 회원에게 보일 캘린더를 미리 본다. 강사가 배정되지 않은 열린 슬롯이 있으면 경고한다.
4. **게시** — 게시해야 회원에게 공개되고 예약을 받는다.
5. **예약** — 회원은 게시된 달의 캘린더에서 슬롯을 골라 **즉시 확정**으로 예약한다(강사가 이미 정해져 있다).

### 3.2 월 스케줄 상태

| 상태 | 의미 | 회원에게 |
|---|---|---|
| 작성 중 | 편성 중, 비공개 | 해당 월은 "준비 중"으로 표시, 예약 불가 |
| 게시됨 | 공개, 예약 접수 중 | 캘린더·슬롯 노출 |
| 마감 | 지난 달 또는 관리자가 접수 종료 | 열람만 가능, 예약 불가 |

### 3.3 월별 템플릿

- 템플릿은 **요일 × 시간 × 강사 × 정원**의 주간 반복 패턴이다.
- 여러 개를 이름을 붙여 저장한다 (예: "평일 기본", "여름 단축 운영").
- 불러온 뒤 해당 월에 맞게 수정할 수 있다. 템플릿 자체는 바뀌지 않는다.
- 현재 편성한 월 스케줄을 **새 템플릿으로 저장**할 수 있다.
- 공휴일 자동 제외 여부는 `[TBD]` (B-13).

### 3.4 게시 후 변경

| 상황 | 처리 |
|---|---|
| 예약자가 없는 슬롯 | 자유롭게 열고 닫고 강사 변경 |
| 예약자가 있는 슬롯의 **강사 변경** | 변경 후 예약자에게 변경 안내 이메일 |
| 예약자가 있는 슬롯 **닫기** | 바로 닫지 않는다. 예약자 수를 보여주고 확인을 받은 뒤 예약을 취소 처리하고 취소 안내 이메일 발송 |
| 지난 슬롯 | 변경 불가 (이력 보존) |

## 4. 캘린더 표시 (회원)

- 예약 페이지(SCR-004)는 **게시된 월의 캘린더**를 보여준다.
- 날짜마다 상태를 표시한다.

| 상태 | 표시 | 선택 |
|---|---|---|
| 예약 가능 | 잔여 슬롯 수 또는 "예약 가능" | 가능 |
| 마감 | "마감" | 불가 |
| 휴무 | "휴무" | 불가 |
| 미게시 월 | "준비 중" | 불가 |

- 날짜를 고르면 그 날의 슬롯 목록이 열리고, 슬롯마다 **시간·담당 강사·잔여 인원**을 보여준다.
- 하루 최대 13슬롯이므로 **오전·오후로 나누어** 표시한다(모바일 대응).
- **예약 가능한 슬롯만 선택**된다. 마감·지난 시간·휴무 슬롯은 선택 자체가 막힌다.
- 색상만으로 상태를 구분하지 않는다(접근성). 텍스트 라벨을 함께 둔다.

## 5. 예약 성립 조건

모두 충족하면 **즉시 확정**된다. 별도 승인 단계는 없다.

1. 로그인한 회원이다 (비회원 불가)
2. 해당 월 스케줄이 **게시** 상태다
3. 슬롯이 열려 있고 강사가 배정되어 있다
4. 슬롯 정원에 여유가 있다
5. 현재 시각 기준 최소 리드타임이 남아 있다 — `[TBD]` (B-5)
6. 1인당 동시 예약 한도를 넘지 않는다 — `[TBD]` (B-5)

> **동시 예약 처리**: 마지막 한 자리를 두 사람이 동시에 누르면 한 명만 성공해야 한다. 서버에서 정원을 확인·차감하는 처리가 필요하다(P4 기술 설계 항목).

**예약 취소**: 회원은 수업 시작 3시간 전까지 마이페이지에서 직접 취소한다. 취소한 자리는 다시 예약 가능해진다.

## 7. 기존 문서·이전 버전과의 차이

| 항목 | ITV-001 (인터뷰) | ITV-003 v0.1 | **이 문서 (v0.2)** |

| 강사 배정 | 수업마다 고정 | 예약 후 관리자가 배정 | **게시 전 월 스케줄 편성 때 미리 배정** |
| 확정 방식 | 즉시 확정 | 신청 → 관리자 확정 | **즉시 확정** (v0.1 방식 취소) |
| 운영 준비 | 없음 | 슬롯 개폐 관리 | **월 단위 편성 + 템플릿 + 게시** |
| 관리자 일상 업무 | — | 예약마다 배정·확정 | **월 1회 편성·게시** (일상 확정 작업 없음) |

> v0.1의 "신청 → 강사 배정 → 확정" 흐름과 그에 딸린 확정 기한(B-9)은 **폐기**한다. 관리자는 매일 확정 작업을 하지 않고, **월 1회 스케줄을 편성·게시**하면 된다. 운영 부담이 크게 줄어든다.
