# 예약 규칙 — 시간 슬롯·운영 시간·캘린더

> **출처**: 2026-09-12 총괄 PM 지시.
> "예약은 레슨 기준으로 하고 06:00~20:00(조절 가능)까지 점심시간을 제외하고 예약을 진행한다. 예약 가능 여부는 캘린더로 표시하여 예약 가능할 때만 예약되도록 한다."
> 추가 지시(같은 날): **레슨 길이는 일반적인 요가 수업에 맞춰 60분으로 한다** (최초 지시의 2시간에서 변경).
>
> 이 문서는 [ITV-001](2026-09-12_customer-interview.md)의 "시간표에서 수업 선택" 서술을 **대체**한다. 정식 요구사항은 CR-001 승인 후 `planning/02_requirements.md`에 반영한다.

## 1. 예약 단위

| 항목 | 값 | 조절 |
|---|---|---|
| 레슨 길이 | **60분** | 관리자 설정 (30분 단위, 예: 60·90·120분) |
| 슬롯 간 휴식 | 없음 (연속 배치) | 관리자 설정 (0·10·15분) |
| 예약 가능 시간대 | **06:00 ~ 20:00** | 관리자 설정, 요일별 |
| 점심시간 | 예약 불가 구간으로 제외 — 시각 `[TBD: 고객 확인 필요]` | 관리자 설정 |

## 2. 슬롯 생성 규칙

1. 운영 시작 시각부터 레슨 길이 단위로 슬롯을 만든다.
2. 점심시간과 겹치는 슬롯은 만들지 않고, 점심시간이 끝난 시각부터 다시 시작한다.
3. 운영 종료 시각을 넘기는 슬롯은 만들지 않는다.

**예시** (06:00~20:00, 60분, 점심 12:00~13:00)

| 오전 (6슬롯) | 오후 (7슬롯) |
|---|---|
| 06:00–07:00 | 13:00–14:00 |
| 07:00–08:00 | 14:00–15:00 |
| 08:00–09:00 | 15:00–16:00 |
| 09:00–10:00 | 16:00–17:00 |
| 10:00–11:00 | 17:00–18:00 |
| 11:00–12:00 | 18:00–19:00 |
| — | 19:00–20:00 |

→ 하루 **13슬롯**. 설정값이 바뀌면 슬롯 수도 자동으로 바뀐다 (예: 90분으로 바꾸면 오전 4 + 오후 4 = 8슬롯, 마지막 19:30–21:00은 운영 종료를 넘어 생성되지 않음).

> 슬롯이 하루 13개이므로 **슬롯 목록은 오전·오후로 나누어 보여준다.** 모바일에서 한 화면에 다 담기지 않기 때문이다(디자인 단계 반영 사항).

## 3. 캘린더 표시

- 예약 페이지(SCR-004)는 **월간 캘린더**를 먼저 보여준다.
- 날짜마다 상태를 표시한다.

| 상태 | 표시 | 선택 |
|---|---|---|
| 예약 가능 | 잔여 슬롯 수 또는 "예약 가능" | 가능 |
| 마감 | "마감" | 불가 |
| 휴무 | "휴무" | 불가 |
| 예약 기간 밖 | 흐리게 | 불가 |

- 날짜를 고르면 그 날의 슬롯 목록이 열리고, 슬롯마다 시간·잔여 인원을 보여준다.
- **예약 가능한 슬롯만 선택할 수 있다.** 마감·지난 시간·휴무 슬롯은 선택 자체가 막힌다.
- 색상만으로 상태를 구분하지 않는다(접근성). 텍스트 라벨을 함께 둔다.

## 4. 신청 성립 조건

모두 충족해야 **신청이 접수**된다. 확정은 §4-2에 따라 관리자가 한다.

1. 로그인한 회원이다 (비회원 불가)
2. 슬롯 정원에 여유가 있다
3. 현재 시각 기준 최소 리드타임이 남아 있다 — `[TBD]` (예: 1시간 전까지)
4. 예약 오픈 범위 안이다 — `[TBD]` (예: 오늘부터 4주 이내)
5. 1인당 동시 예약 한도를 넘지 않는다 — `[TBD]`
6. 휴무일·점심시간이 아니다

> **동시 신청 처리**: 마지막 한 자리를 두 사람이 동시에 누르면 한 명만 성공해야 한다. 서버에서 정원을 확인·차감하는 처리가 필요하다(P4 기술 설계 항목).

## 4-2. 강사 배정과 예약 확정

> **PM 지시 (2026-09-12)**: 등록된 모든 강사는 기본적으로 어느 슬롯에나 배정할 수 있다. 예약이 들어오면 관리자가 강사를 슬롯에 배정하고 예약을 확정한다.

### 상태 흐름
```
회원 신청  →  [신청 접수]  →  관리자 강사 배정 + 확정  →  [확정]
                  │                                          │
                  ├─ 관리자 반려 ──────────────→ [취소]        └─ 회원/관리자 취소 → [취소]
                  └─ 회원 취소 ────────────────→ [취소]
```

| 상태 | 의미 | 회원 화면 표시 |
|---|---|---|
| 신청 접수 | 자리를 확보했으나 강사 미배정 | "확정 대기" |
| 확정 | 강사가 배정되어 수업 확정 | "확정 (담당 강사 ○○○)" |
| 취소 | 회원 취소, 관리자 반려, 슬롯 폐쇄 | "취소" + 사유 |

### 관리자 작업
1. 관리자 화면에서 **신청 목록**(슬롯·날짜·신청자·인원)을 본다.
2. 슬롯에 **강사를 배정**한다. 등록된 강사 전원이 선택 대상이다.
3. 확정하면 신청자에게 **확정 안내 이메일**(일시·강사명)이 나간다.
4. 운영이 어려우면 **반려**하고 사유를 적는다 → 신청자에게 취소 안내가 나간다.

### 규칙
- **한 강사는 같은 시간대의 두 슬롯에 동시에 배정될 수 없다.** 배정 화면에서 겹치는 강사는 선택할 수 없게 막는다.
- 강사가 배정되지 않은 예약은 확정할 수 없다.
- 확정 후 강사를 바꿀 수 있다. 변경하면 신청자에게 변경 안내를 보낸다.
- 슬롯 단위로 한 번에 배정·확정할 수 있어야 한다(같은 슬롯의 신청자 여러 명을 한 번에 확정).
- **강사 목록**은 관리자 화면에서 등록·수정한다(이름·활성 여부). 강사 소개 페이지(SCR-002)와 같은 자료를 쓸지는 P4에서 정한다.

### 회원에게 보내는 안내
| 시점 | 내용 |
|---|---|
| 신청 접수 | "신청이 접수되었습니다. 확정되면 다시 안내드립니다" |
| 확정 | 일시·담당 강사·장소, 취소 마감 시각 |
| 반려·취소 | 사유와 대체 안내 |

## 4-1. 슬롯 운영 관리 (관리자)

> **PM 지시 (2026-09-12)**: 슬롯은 관리자가 유연하게 열고 닫아 관리한다.

슬롯 생성 규칙(§2)은 **후보 슬롯**을 만들 뿐이고, 실제로 예약을 받을지는 관리자가 정한다.

| 단계 | 내용 |
|---|---|
| ① 후보 슬롯 | 운영 시간·레슨 길이·점심시간 설정에 따라 자동 생성 (하루 13개) |
| ② 요일별 기본 패턴 | 요일마다 어떤 슬롯을 기본으로 열지 지정 (예: 평일은 06·07·10·18·19시, 토요일은 09~12시) |
| ③ 날짜별 예외 | 특정 날짜의 슬롯을 개별로 열거나 닫음 (강사 사정, 행사, 단체 대관 등) |
| ④ 휴무일 | 하루 전체를 닫음 |

- **닫힌 슬롯은 캘린더에 나타나지 않거나 "운영 안 함"으로 표시**되고 선택할 수 없다.
- 한 번에 여러 슬롯을 열고 닫을 수 있어야 한다 (날짜 범위 + 요일 + 시간대 선택).
- 슬롯별로 **정원을 다르게** 정할 수 있다 (예: 오전 6시는 4명, 저녁 7시는 8명).

### 예약이 있는 슬롯을 닫을 때
| 상황 | 처리 |
|---|---|
| 예약자가 없는 슬롯 | 즉시 닫힘 |
| 예약자가 있는 슬롯 | **바로 닫지 않는다.** 관리자에게 예약자 수를 보여주고 확인을 받은 뒤, 예약을 취소 처리하고 취소 안내 이메일을 보낸다 |
| 이미 지난 슬롯 | 변경 불가 (이력 보존) |

## 6. 기존 문서와의 차이

| 항목 | ITV-001 (인터뷰) | 이 문서 (PM 지시) |
|---|---|---|
| 예약 대상 | 수업(클래스) 시간표에서 선택 | **시간 슬롯**에서 선택 |
| 운영 시간 | 평일 06:00~22:00 / 주말 09:00~18:00 | **06:00~20:00** (요일별 설정 가능) |
| 점심시간 | 언급 없음 | **예약 불가 구간** |
| 화면 | 시간표 목록 | **월간 캘린더 → 슬롯 목록** |
| 확정 방식 | 즉시 확정 (정원 안이면 바로 확정) | **신청 → 관리자 강사 배정 → 확정** |
| 강사 | 수업마다 강사 고정 | 슬롯에 강사 없음. **예약이 들어온 뒤 관리자가 배정** |

→ 상충하는 부분은 **이 문서가 우선**한다. 다만 주말 운영 시간은 확인이 필요하다.

> **중요**: 확정 방식이 "즉시 확정"에서 "관리자 확정"으로 바뀌었다. [ITV-001](2026-09-12_customer-interview.md) Q1의 "전화로 일일이 확인하는 일을 줄인다"는 목적은 **전화 → 온라인 신청 전환**으로 달성되고, 확정 단계는 관리자 작업으로 남는다. 관리자의 일일 확정 작업이 새로 생기므로, 운영 부담을 고객에게 확인받아야 한다(B-9).
