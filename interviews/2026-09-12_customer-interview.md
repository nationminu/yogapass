# 고객 인터뷰 기록 (가상)

> ## ⚠️ 이 문서의 성격
> **실제 고객에게 받은 답변이 아니다.** 총괄 PM의 지시로 오케스트레이터가 고객(요가패스) 역할을 맡아, 계획서 §2.4의 확인 질문 27건과 기획팀 추가 4건(T-28~T-31)에 **업종 상식과 요청 원문(CR-000)에 근거해 답한 시뮬레이션**이다.
>
> - 여기의 모든 값은 **가정**이며, 실제 고객 회신으로 대체되어야 한다.
> - 주소·전화·요금·강사 정보 등 **사실 확인이 필요한 값은 그대로 산출물에 옮기지 말 것.** 산출물에는 `[TBD: 고객 확인 필요]`를 유지하고, 이 문서는 **범위·방식 결정(ADR-001)과 일정 판단에만** 사용한다.
> - 실제 회신이 오면 이 문서와 대조해 차이를 CR로 처리한다.
>
> **PM 추가 지시 (2026-09-12)**: 회원가입·회원관리를 범위에 포함한다. **회원가입한 사람만 예약할 수 있다.** → 계획서 v1.0 §2.2의 "회원가입·로그인 제외"가 뒤집히므로 변경 요청(CR-001) 대상이다.

## 2. 묶음 ① — 범위·일정 결정 질문 (12건)

| # | 질문 요지 | 고객 답변 (가상) | 결정 영향 |
|---|---|---|---|
| Q23 | 예약 대상: 체험/상담인가, 회원 정규 수업인가 | **둘 다.** 다만 이제는 **둘 다 회원가입 후** 신청하게 하고 싶다. 체험 신청도 회원 정보를 남겨야 이후 관리가 된다 | 범위 확대 (회원 기능) |
| Q1 | 예약 방식: 접수형 / 즉시 확정형 / 외부 서비스 | **즉시 확정형.** 회원이 로그인해서 시간표에서 수업을 고르면 정원 안에서 바로 확정되게. 전화로 일일이 확인하는 일을 줄이는 게 목적이다 | **B안(자체 예약 시스템)** |
| Q2 | 예약조회 범위 | 마이페이지에서 **내 예약 목록 확인 + 스스로 취소**(수업 시작 3시간 전까지). 지난 수강 이력도 보이면 좋겠다 | 회원 전용 조회 |
| Q24 | 상태 변경 수단 | **관리자 화면**이 필요하다. 대표와 실장 2명이 쓸 것이다. 예약 확인·취소, 시간표 등록, 회원 목록 확인 | 관리자 기능 포함 |
| Q25 | 예약번호 전달 수단 | 회원 로그인으로 조회하므로 **예약번호는 불필요**. 예약 완료 시 **이메일 안내**만 받으면 된다 | 예약번호 체계 폐기 |
| Q3 | 현재 쓰는 예약·회원관리 서비스 | 없다. 엑셀과 전화. 네이버 예약은 수수료·이탈 때문에 쓰지 않으려 한다 | 외부 서비스(C안) 비선호 |
| Q4 | 문의 폼은 예약과 별개인가 | **별개다.** 수강료·개인 레슨 같은 일반 문의용. 비회원도 남길 수 있어야 한다 | 문의 폼 유지(비회원 허용) |
| Q5 | 오픈 희망일·단계 오픈 수용 | 10월 말이면 좋지만 **기능이 더 중요하다.** ① 소개 페이지를 먼저 열고 회원·예약을 나중에 여는 **단계 오픈 수용** ② 늦어도 **11월 중순**까지는 전체 오픈 | 단계 오픈 가능 |
| Q6 | 오픈 후 직접 수정 필요 여부 | **시간표와 공지는 직접 수정**해야 한다. 매주 바뀐다. 소개 문구·이미지는 요청해도 된다 | 관리자 화면에 시간표·공지 |
| Q7 | 다국어 | 불필요. 한국어만 | 범위 유지 |
| Q8-1 | 알림 수신 방식 | 예약은 즉시 확정이라 실시간 알림은 필수 아님. **이메일 요약**과 관리자 화면 목록으로 충분. 문자·알림톡은 비용 때문에 이번엔 제외 | 이메일 알림 |
| Q20-1 | 외부 서비스 월 예산 | **월 5만 원 이내.** 가능하면 무료 구간에서 시작하고 회원이 늘면 올리겠다 | 호스팅·DB 선택 제약 |
