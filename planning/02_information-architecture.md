# 정보구조 (IA) — 강남 요가패스 홈페이지

> **읽는 법**
> - 메뉴 페이지는 **6종으로 고정**이다(계획서 §2.1 페이지 추가 원칙). 폼 완료·404 같은 보조 화면은 페이지 수에 넣지 않는다.
> - **예약(SCR-004)·예약조회(SCR-005)·예약 완료(SCR-007)는 예약 영역**이며 ADR-001 결정 대기다. 본문은 기준안 A'-1 기준이고, 선택지별 IA 차이는 §7에 있다.
> - 문의 폼 위치는 **Q4 회신 전 가정**이다(§2.3).
> - 모든 사실 정보는 `[TBD: 고객 확인 필요]`다.

## 1. 사이트맵

```
홈 / 메인 (SCR-001)  —  /
├── 요가 강사 소개 (SCR-002)  —  /instructors
├── 오시는 길 (SCR-003)  —  /location
│   └── [섹션] 문의하기 (일반 문의 폼)  —  /location#contact   ※ 위치는 Q4 회신 전 가정
├── 예약 (SCR-004)  —  /reservation                      ▲ 예약 영역 (ADR-001 대기)
│   └── 예약 신청 완료 (SCR-007, 보조)  —  /reservation/complete   ▲ 예약 영역
├── 예약조회 (SCR-005)  —  /reservation/lookup           ▲ 예약 영역
└── 개인정보 처리방침 (SCR-006)  —  /privacy

[보조] 404 (SCR-008)  —  존재하지 않는 모든 경로
```

- 계층은 **1depth 평면 구조**다. 페이지가 6개뿐이고 모바일에서 2depth 메뉴는 조작 부담만 늘리므로 하위 메뉴를 두지 않는다.
- 예약 완료(SCR-007)는 예약 페이지의 후속 화면이므로 URL을 `/reservation/` 하위에 둔다. 메뉴에는 노출하지 않는다.
- 예약조회도 예약과 같은 맥락이라 `/reservation/lookup`으로 두되, **주 메뉴에는 독립 항목으로 노출한다**(고객이 5개 페이지로 요청했고, 신청자가 직접 찾아와야 하는 화면이기 때문).

## 4. 주요 사용자 흐름

### Flow-1: 신규 방문자(U-1) — 검색 유입 → 신뢰 확인 → 예약 신청 **(핵심 전환 흐름)**
| 단계 | 화면 | 사용자 행동 | 다음 화면 |
|---|---|---|---|
| 1 | (외부) 검색 결과 | "강남 요가" 등으로 검색해 사이트를 찾는다 | SCR-001 |
| 2 | SCR-001 | 첫 화면에서 스튜디오가 어디서 무엇을 하는지 확인한다 | SCR-001 (스크롤) 또는 SCR-004 (즉시 전환) |
| 3 | SCR-001 | 강점·강사 미리보기·위치 요약을 훑는다 | SCR-002 또는 SCR-003 또는 SCR-004 |
| 4 | SCR-002 | 강사 경력·담당 수업을 보고 신뢰를 판단한다 | SCR-004 |
| 5 | SCR-003 | 위치·교통·운영시간이 다닐 만한지 확인한다 | SCR-004 |
| 6 | SCR-004 | 신청 항목을 입력하고 개인정보 동의 후 제출한다 | SCR-007 |
| 7 | SCR-007 | 예약번호를 확인·보관하고, 스튜디오 연락 안내를 읽는다 | 종료 또는 SCR-005 |

> **전환 거리 원칙**: 어떤 화면에서든 예약까지 **1번의 조작**(하단 고정 바 또는 헤더 버튼)으로 도달한다(REQ-F-003).
> **이탈 지점 주의**: 4·5단계에서 정보가 `[TBD]`로 비어 있으면 신뢰가 깨져 이탈한다 → REQ-N-023(오픈 시 TBD 0건)과 직결.

### Flow-2: 신청자(U-2) — 예약조회 ▲ 예약 영역
| 단계 | 화면 | 사용자 행동 | 다음 화면 |
|---|---|---|---|
| 1 | (외부) 재방문 | 사이트에 다시 들어온다 | SCR-001 |
| 2 | SCR-001 | 메뉴에서 '예약조회'를 고른다 | SCR-005 |
| 3 | SCR-005 | 예약번호 + 휴대폰 번호를 입력하고 조회한다 | SCR-005 (결과 상태) |
| 4a | SCR-005 | (성공) 신청 내용과 '접수 완료'를 확인하고, **확정은 스튜디오 연락으로 안내된다는 문구**를 읽는다 | 종료 |
| 4b | SCR-005 | (실패) 공통 실패 안내를 보고 전화 문의로 이동한다 | 전화 앱 |

> 완료 화면(SCR-007)에서 바로 조회 화면으로 가는 링크도 제공한다(REQ-F-R-027).
> A안으로 결정되면 3~4단계가 사라지고 SCR-005는 안내 화면이 된다(§7).
