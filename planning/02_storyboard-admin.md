# 화면정의서 (스토리보드) — 강남 요가패스 · 관리자 영역 (`SCR-900~999`)

> **이 문서의 범위: 관리자 전용 영역 18화면(SCR-900~917). 전부 2차(2027-01-22(금) 오픈)다.**
> 공개·회원 영역 27화면은 `02_storyboard.md`에 있다. **분리한 이유**: 한 문서로는 45화면이 관리되지 않고, 관리자 영역은 사용자·목표·반응형 기준·색인 정책이 전부 달라 **검토도 영역 단위로 나누는 편이 정확하다**(CR-001 영향도 planner R-9, RSK-021).

## 공통 규칙

> **규칙 본문을 여기에 복제하지 않는다.** 아래 표는 "어디를 보라"와 "관리자 영역에서만 다른 것"만 적는다.

**관리자 셸 (전 화면 공통 · 화면마다 반복하지 않는다)**

| 영역 | 구성 |
|---|---|
| **좌측 사이드바** (1024px 이상 고정 펼침 / 모바일 지원 화면은 상단 드로어) | ① 대시보드 ② **스케줄**(월 편성 · 월 템플릿 · 게시) ③ **예약** ④ **상담**(미처리 건수 배지) ⑤ **회원**(회원 목록 · 경고 기록) ⑥ **콘텐츠**(강사 · 레슨 유형 · 공지) ⑦ **설정** → **기능 12종 전부 도달**(REQ-F-A-002) |
| **상단바** | 빵부스러기(현재 위치) / **알림 배지**(신규 상담 n · 다음 달 미게시 경고) / 계정 메뉴(로그아웃) / 개인정보 처리방침 링크 |
| **본문** | 화면별 정의 |
| **푸터(축약)** | 개인정보 처리방침 링크 + 버전 표기만 |

**작성 규칙**

- 실제 문구 초안은 "큰따옴표". 고객만 아는 사실 정보는 `[TBD: 고객 확인 필요 — T-x]`.
- **초기 설정값·초기 등록 데이터는 제작이 초안을 넣고 고객이 오픈 후 관리자 화면에서 직접 바꾼다.** 제작이 고정값으로 박지 않는다(REQ-C-A-002).
- **빈 상태 문구에 "준비 중"을 쓰지 않는다.**
- 와이어프레임은 **1280px 기준**(관리자 기본 작업 환경)이며, 모바일 지원 화면에만 360px를 함께 둔다.
- 회원 개인정보가 보이는 화면(SCR-908·909·910·913·914)은 **표시 항목을 명시적으로 고정**하고 그 밖의 항목을 화면·응답에 담지 않는다.

### 예외 · 상태

| 상황 | 처리 |
|---|---|
| **조작 수단 노출 금지** | 편성·설정 UI를 **CSS로 감추는 방식이 아니라 렌더하지 않는다.** DOM에 남기면 "조작 수단이 노출되지 않는다"(REQ-N-A-001)를 만족하지 못하고, 키보드·스크린리더로 도달할 수 있다 |

| 서버 권한 검사 | 뷰포트와 무관하게 `/admin/**` 권한 검사는 그대로 수행된다(REQ-F-A-002) |
| 창 크기 변경 | 리사이즈로 1024px를 넘으면 **새로고침 없이 원래 화면으로 전환**된다. 위 "렌더 분기 방식"의 클라이언트 조건부 마운트로 구현된다(세부는 P4) |
