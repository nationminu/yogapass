# 리뷰: P2 기획 산출물 3종 v0.3 — designer (R3)

> **이번 라운드는 범위를 좁힌 확인 검토다.** ① R2 지적 12건의 반영 여부만 원문에서 확인하고 ② 그 반영 때문에 **새로 생긴 모순**만 추가 지적한다. 이미 해결된 사항과 v0.3 이전부터 있던 항목은 다시 다루지 않으며, 새 요구도 추가하지 않는다.

## 1. 총평

- **R2 지적 12건(Must 1 · Should 7 · Could 4)은 전부 실제로 반영됐다.** 처리 결과 열의 서술과 원문이 모두 일치했고, "반영"이라고만 적고 본문이 그대로인 항목은 0건이다.
- **Must #1(G-9)은 designer 권고안 ⓐ 그대로 반전됐고, 문서 8곳이 같은 값을 가리킨다.** 실제 확인: 요구사항 §3.0 G-9(L83) / REQ-F-003 ①·⑤(L94) / REQ-N-002(L299) / IA §2.3 요약(L84)·§5 고정 바 행(L178)·§5.1 G-9 행(L199) / 화면정의서 공통 규칙(L18·L22) 및 SCR-003(L269)·SCR-004(L352)·SCR-005(L421) 예외 표. 전 문서에서 "일시 숨김"을 지시하는 문장은 0건이며, 남아 있는 "숨김" 언급은 전부 "삭제했다"는 이력 서술이다. **권고와 다르게 처리된 부분은 없다.** 오히려 권고에 없던 검증 수단(REQ-F-003 ⑤ + D-12 잠정 260px 뷰포트 축소 + iOS 미검증 처리 규칙)까지 붙어 P5 판정이 가능해졌다 — 디자인 관점에서 수용한다.
- **새로 생긴 문제는 Should 2건 · Could 2건이고 Must는 없다.** 핵심은 **G-9(키보드 중에도 고정 바 유지)와 G-6 단서(전화번호 미확정 시 SCR-004 고정 바 미노출)가 v0.3에서 동시에 들어오면서, REQ-F-003 수용 기준 ④·⑤에만 SCR-004 제외 단서가 빠진 것**(#1)이다. ②와 REQ-N-002에는 제외가 들어갔는데 ④·⑤에는 없어, Q14 미회신인 현재 상태로 P5를 돌리면 SCR-004에서 ④·⑤가 자동 Fail한다. 한 줄 추가로 끝난다.
- **P3 착수 관점**: R2에서 차단 요소로 지목했던 #1(G-9)·#2(768px 헤더 CTA)는 둘 다 해소됐다. 고정 바 CMP(기본형 / SCR-004 전폭 1버튼 / 전화번호 미확정 시 미노출)는 지금 값으로 확정해 그릴 수 있다. 남은 #2(768px 헤더 내비 방식)만 정해지면 태블릿 헤더까지 그릴 수 있고, 이는 컨셉 시안 단계를 막지 않는다. **실제 제약은 여전히 고객 회신(Q10 로고·브랜드 색상 / Q21 참고 사이트 / Q11 사진 조달)이다.**

## 3. 검토 관점 체크리스트 (R3 범위)

- [x] R2 Must #1이 권고 방향(ⓐ 삭제)대로 반전됐는가 — **그대로 반전됐다.** G-9 · REQ-F-003 ①⑤ · REQ-N-002 · IA 3곳 · 화면정의서 4곳, 총 8곳의 값이 동일
- [x] 권고와 다르게 처리된 부분이 디자인 관점에서 수용 가능한가 — **수용한다.** 추가된 것은 검증 수단(REQ-F-003 ⑤ + D-12 260px + iOS 미검증 처리)뿐이고, 디자인이 정의할 상태(키보드 위로 밀려 올라간 고정 바)가 명확하다
- [x] R2 나머지 11건이 문서 원문에 실제로 반영됐는가 — 11건 전부 원문 대조 확인(위 §2의 행·줄 번호)
- [x] 반영 때문에 새로 생긴 모순이 있는가 — **4건.** G-6 단서 × REQ-F-003 ④⑤ 적용 범위(#1), 768px 헤더 내비 방식 두 값(#2), "모든 뷰포트의 헤더 예약 버튼" 표현(#3), description 초안 안의 강조 마크업(#4)
- [x] 고정 바 규칙 변경이 다른 화면·컴포넌트와 충돌하는가 — **SCR-001·002·003·005·006·007·008은 충돌 없음.** 세 폼 화면 예외 표가 모두 같은 문장이고, 와이어프레임 표기도 유지됐다. 충돌은 SCR-004 한 화면에만 남았다(#1)
- [x] P3 고정 바 CMP를 지금 값으로 확정할 수 있는가 — **가능하다.** 기본형(2분할 + 8px) / SCR-004 전폭 1버튼 / 전화번호 미확정 시 미노출 / 키보드 활성 시 밀려 올라감, 4개 상태로 정의된다
