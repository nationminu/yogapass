# 리뷰: P2 기획 산출물 v0.3 (요구사항·IA·화면정의서) — developer (R3)

> **검토 범위 한정**: 내 R2 지적 11건의 반영 여부와, 그 반영 때문에 새로 생긴 기술 문제만 본다. 문서 전체 재검토가 아니다. 공수 재산정(계획서 개정)은 pmo로 이관됐으므로 지적하지 않는다 — 단 G-9 관련 수치는 이번 개정으로 값 자체가 바뀌므로 #2 안에서 정정한다.

## 1. 총평
- **R2 지적 11건 중 10건 해결, 1건은 pmo 이관(#8).** 유일한 Must였던 **§4.5 표 (1)↔(2) C안 판정 충돌은 해소됐다.** 표 (1) C열 4칸(R-001·007·009·011)이 "삭제 → 변경 / 임베드·이동 구분"으로 정정됐고, 표 (2) C행·A행도 같은 표기 체계로 재작성됐다. **표 (1)·(2)를 REQ 단위로 전수 대조한 결과 판정이 서로 반대인 칸은 0건이다.** 다만 표 (2) C행의 "변경(남음)" 목록에서 **REQ-F-R-004(개인정보 동의) 한 건이 빠졌다** — 표 (1) C열은 "변경"으로 판정하고 있고, C행 말미에는 "표 (1) C열과 값이 일치한다"고 적혀 있어 그 문장이 사실과 다르다(#1, Should).
- **가장 중요한 신규 문제는 G-9 반전의 구현 수단이다.** 규칙 방향(키보드 중에도 고정 바 유지)은 옳고 REQ-F-003 ⑤도 판정 가능한 형태다. 그러나 문서가 유일한 구현 수단으로 적은 **`interactive-widget=resizes-content`는 WebKit(iOS Safari, 그리고 iOS의 모든 브라우저)에서 지원되지 않는다**(Chromium Android 108+ / Firefox Android 132+만 지원). iOS는 키보드가 레이아웃 뷰포트를 줄이지 않으므로 `position:fixed` 하단 바가 **키보드 뒤로 가려진다** — 즉 iOS에서는 **검증하기 전에 이미 미충족이 예정돼 있다.** 이를 D-1의 "미검증 → Block 아님" 규칙으로 덮으면 Must 브라우저(REQ-N-003)에서 실패가 예정된 채 게이트를 지나간다. `visualViewport` 기반 폴백을 수단에 함께 적으면 해결되며, **그 대신 §7 머리말의 "G-9 삭제로 -0.25작업일 확정 감소"는 성립하지 않는다**(#2).
- 그 밖에 이번 개정으로 생긴 기술 문제는 **검증 수단의 유효성 2건**이다 — ① D-12(뷰포트 260px 축소)는 `interactive-widget` 지정 여부와 무관하게 항상 통과하므로 G-9를 판정하지 못한다(거짓 Pass, #4) ② REQ-F-R-006 수용 기준 ④의 예시 번호에 `0`·`1`이 없어 혼동 문자 치환 규칙을 검증하는 유일한 변형이 무효가 됐다(#5). **Must는 없다. 5건 모두 문구 1~3줄 수정으로 끝난다.**

| 미지원 | **WebKit 전체** — iOS Safari 및 iOS의 모든 브라우저(iOS Chrome·Edge도 WebKit). 데스크톱 브라우저는 가상 키보드가 없어 해당 없음 |
| 기본값 | `resizes-visual`(키보드가 레이아웃 뷰포트를 줄이지 않음). 즉 **지정하지 않으면 Android에서도 고정 바가 가려질 수 있다** — 메타 태그 지정 자체는 필요하다 |
| iOS 동작 | 키보드가 비주얼 뷰포트만 줄이고 레이아웃 뷰포트는 그대로 → `position:fixed; bottom:0` 요소가 키보드 뒤에 남는다. 회피 수단은 `visualViewport`의 `height`·`offsetTop` 기반 위치 보정뿐이다(`env(keyboard-inset-height)`·VirtualKeyboard API도 WebKit 미지원) |
| 주의 | iOS 일부 버전에서 키보드를 닫은 뒤 `visualViewport.height`·`offsetTop`이 즉시 복원되지 않는 사례가 보고돼 있다 → 폴백 구현 시 복원 처리 필요 |
| 재확인 | 위 지원 범위는 문서 기준이며, **P4에서 실기기로 재확인**한다(D-1 결정 결과에 따름). 일부 블로그의 "iOS 15부터 지원" 주장은 1차 출처에서 확인되지 않았다 |
