# 리뷰: P3 디자인 산출물(컨셉 v0.2 · 시스템 v0.1 · 페이지 디자인 v0.1 + 목업 4종) — planner (R1)

## 1. 총평

화면정의서 v1.0의 1차 6화면 섹션·문구·인터랙션·예외 상태가 **거의 그대로** 디자인에 들어왔다. 특히 ⓐ 확정문·자리표시자 문구를 임의로 바꾸지 않은 점 ⓑ `[TBD]`를 실제 값처럼 보이게 만들지 않은 점 ⓒ **값 복제 금지 원칙**(§3.0 G-2/G-3, IA §2.1)을 토큰 참조 구조로 정확히 구현한 점은 기획이 v0.6에서 강화한 규칙이 의도대로 작동했음을 보여준다. `--fixed-bar-h` 하나로 G-3 파생값이 따라오는 구조는 P5 판정 비용을 실제로 줄인다.

**Must는 1건이다.** `SCR-003`의 `≥1280px` **헤더 주 CTA 자기 참조 처리**가 빠졌다. 이 구간은 고정 바 미노출 구간이라 헤더 CTA가 **유일한 주 CTA**이고, 현재 명세·목업은 `/location`에서 `/location#contact`로 가는 강조 버튼을 `aria-current` 없이 그대로 두어 **IA §2.1 마지막 줄·요구사항 §3.0 G-6 ①과 충돌**한다. 페이지 디자인 §10의 "화면정의서와 충돌하는 설계는 없다"는 이 한 건에서 성립하지 않는다. 수정은 **표 한 행 추가** 수준이다.

designer가 확인을 요청한 2건(z-index 쌓임 순서 · 고정 바 60px → G-3 76px)은 **둘 다 승인**한다. §10의 9개 항목도 전부 타당하다(§3.1·§3.2 참조).
