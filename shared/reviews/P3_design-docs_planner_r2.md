# 리뷰: P3 디자인 산출물 v0.2 — planner (R2 · 확인 검토)

> **이 리뷰의 범위는 R1 Must #1 한 건이다.** R1 §5에 적은 대로 "#1이 반영되면 즉시 승인"이라는 예고에 따른 확인 검토이며, **Should·Could 재확인과 문서 전체 재검토는 하지 않았다.** 따라서 이 문서에 R1 #2~#9에 대한 판정은 없다(전부 R1에서 게이트 비차단으로 이미 닫혔다).

## 1. 총평

**Must #1은 해소됐다. 판정은 승인이다.**

designer는 두 안 중 **ⓒ("자기 참조 → '전화 문의' 대체(H2), 대표 전화 `[TBD]` → 미노출(H3)")** 를 택했고, 이 선택은 planner가 R1 #1 제안에 적은 **"고정 바 S2/S3와 같은 판단 축"** 을 그대로 따른다. 결과적으로 `<1280px`(고정 바 S1/S2/S3)와 `≥1280px`(헤더 H1/H2/H3)가 **하나의 분기 규칙(URL 비교 + 전화번호 데이터 유무)** 을 공유하게 되어, 구현이 두 벌이 되지 않고 P5 판정 기준도 한 축으로 정리된다. 기각한 두 안(비활성 버튼 / 앵커 전환)의 사유도 타당하다 — 특히 ⓑ 기각 근거(이미 페이지 헤더 이동 칩이 같은 역할을 한다)는 G-8의 취지와 일치한다.

반영 위치도 R1이 지적한 4곳에 빠짐없이 들어갔고(디자인 시스템 CMP-003 / 페이지 디자인 §1·§4.4 (2)·§10 / 목업 데스크톱 프레임), **§10의 "충돌 없음" 서술도 정정**됐다. `aria-current` 처리를 "헤더 주 CTA에는 어떤 상태에서도 부여하지 않는다"로 못박은 것은 R1 제안보다 한 걸음 더 나간 명확화이며 **IA §2.1의 표기가 오히려 부정확했음을 드러냈다** — 이 부분은 planner가 같은 배치에서 기획 3문서를 v1.1로 개정해 맞췄다(§2 표 참조). 이 처리로 새로 생긴 모순은 없다.

## 3. 새 모순 점검 (이 처리로 생긴 부작용만)

| # | 점검 항목 | 결과 |
|---|---|---|
| 1 | **고정 바 규칙(G-5·G-6)과 충돌하는가** | 없음. H1↔S1 / H2↔S2 / H3↔S3로 조건이 1:1 대응하고, 두 요소가 동시에 존재하는 구간이 없다(G-1: `≥1280px`는 고정 바 미노출) |
| 2 | **G-8("헤더 주 CTA는 `≥1280px`에만")과 충돌하는가** | 없음. H1~H3은 전부 `≥1280px` 안에서의 상태 분기이며 `768~1279px`에 CTA를 되살리지 않는다 |
| 3 | **1차 전환 경로가 끊기는가** | 끊기지 않는다. H3은 **전환 목적지 화면(SCR-003) 자신**에서만 발생하고, 같은 화면에 이동 칩·`#contact` 폼·대체 연락 안내가 있다. 다른 1차 화면은 전부 H1이다 |
| 4 | **`aria-current` 규정이 IA와 어긋나는가** | **어긋났고, 기획 쪽을 고쳤다.** IA §2.1 마지막 줄이 헤더 주 CTA를 `aria-current` 대상에 넣고 있었으나, 이는 처리 방식이 정해지기 전의 표기였다. designer 판단(대체·미노출로 처리하므로 "현재 위치" 표시 대상이 아니다)이 맞아 **IA v1.1에서 "GNB 항목에만"으로 정정**했다. 디자인 수정 요청 없음 |
| 5 | **REQ-F-003 수용 기준으로 판정 가능한가** | v1.0 기준으로는 **판정 불가였다** — ③이 "1280px에서 주 CTA가 보인다(자기 참조 화면에서는 `aria-current="page"`)"로 되어 있어 H2·H3과 정면으로 어긋났다. **요구사항 v1.1에서 ③을 ③-1~③-5로 분해**해 세 상태의 기대 결과를 각각 적었다. designer 산출물 수정 불필요 |
| 6 | **`[TBD]` 노출·값 복제 규칙(REQ-N-023 · G-2/G-3)을 깨는가** | 깨지 않는다. H3은 요소 자체를 렌더하지 않으며 목업에서도 문자열·빈 버튼이 없다. 새로 도입된 값·수치도 없다(상태 정의뿐) |

**참고(지적 아님) 2건** — 게이트·구현·판정에 영향이 없어 등급을 매기지 않는다.
- H2 상태에서는 헤더에 **전화번호 텍스트 + "전화 문의" 버튼**이 함께 놓인다. `<1280px`에서 **헤더 전화 아이콘 + 고정 바 "전화 문의"(S2)** 가 공존하는 이미 합의된 구성과 같은 형태이므로 새 모순이 아니다. P5는 이를 결함으로 잡지 않는다.
- 목업 데스크톱 프레임은 **H3만** 그려져 있다(고정 바는 S3·S2 두 상태를 그렸다). H2는 대표 전화 확정 시점에나 실현되는 상태이고 명세가 문장으로 닫혀 있어 **추가 요청하지 않는다.**
