# DEF-005 공통 헤더·푸터의 터치 타깃이 44px 미만이고 푸터 저작권 문구가 13px로 렌더된다

## 환경
- 실행 방법 / URL: 운영 미리보기 `http://localhost:8001/location` 외 전 화면
- 브라우저 · 뷰포트: Chrome headless(puppeteer-core) **360×780**, `isMobile: true`, `hasTouch: true`
- 대상 버전: 개발 보고서 v0.3, 이미지 `yogapass-app:0.1.0-qa1`

## 재현 절차
1. `cd qa/tools && BASE=http://localhost:8001 node a11y-detail.js`
   (360px에서 `a,button,input,select,textarea,summary`의 `getBoundingClientRect()`를 재고, 텍스트 리프 노드의 `font-size`를 잰다)
2. `node probe3.js` 로 Tab 순회 시 각 요소의 실측 크기를 교차 확인한다.

## 기대 결과
근거:
- **REQ-N-006 ②**(Must) — *"모든 조작 요소의 터치 타깃 **44×44px 이상**, 인접 간격 8px 이상"* (예외는 ②-1 격자형 컴포넌트뿐이며 1차에는 해당 없음)
- **REQ-N-006 ⑤**(Must) — *"본문 최소 14px"*
- 디자인 시스템 v1.1 §타이포 — *"문장(본문·설명·오류·안내)의 하한은 14px이다. 어떤 뷰포트에서도 14px 미만으로 내리지 않는다."* 14px 미만 허용은 **3가지(eyebrow 12.5px / 데이터 표 헤더 13px·2차 관리자 / 상태 배지 12px·2차 관리자)** 뿐이다.

**① 터치 타깃 44px 미만 (전 화면 공통 요소)**

| 요소 | 실측 | 위치 | 비고 |
|---|---|---|---|
| `a.logo` (헤더 로고 = 홈 링크) | **140×32** | 헤더 | 디자인 시스템 §헤더 표가 *"로고(높이 32px, 폭 ≤140px)"* 로 규정 → **REQ-N-006 ②와 디자인 명세가 상충**한다(아래 "확인 필요" 참조) |
| 푸터 링크 "홈" | **328×32** | 푸터 | |
| 푸터 링크 "강사 소개" | **328×32** | 푸터 | |
| 푸터 링크 "오시는 길" | **328×32** | 푸터 | |
| 푸터 링크 "문의하기" | **328×32** | 푸터 | |
| 푸터 링크 "개인정보 처리방침" (`a.strong`) | **328×32** | 푸터 | |

44px을 충족하는 것(참고): `summary.mnav-btn` 44×44 · `a.chip` 119×44·86×44 · `input.inp` 328×52 · `textarea.inp` 328×191 · `button.btn` 328×52 · `a.skip` 121×48. **동의 체크박스는 `input`이 24×24지만 `label`이 292×77이라 클릭 영역이 디자인 명세(행 전체 min-height 44px)를 충족**하므로 이 티켓 대상이 아니다. 문단 안 인라인 링크(`a.link` 216×16, 처리방침 보기)도 디자인 시스템 §578의 "WCAG 2.5.5 인라인 예외"에 해당해 제외했다.

**② 본문 글꼴 14px 미만**

| 요소 | 실측 | 문구 | 판정 |
|---|---|---|---|
| `p.ft-muted.ft-small.ftr-copy` | **13px** | "© 2026 요가패스" | **위반** — 허용 예외 3가지 어디에도 해당하지 않는다 |
| `span.eyebrow` | 12.5px | "강남 요가 스튜디오" | 허용(디자인 시스템 eyebrow 예외) — 위반 아님 |
| 로고 SVG 내부 `<text>` | 10.5px | "강남 요가 스튜디오" | 그래픽 텍스트 — 위반 아님 |

## 확인 필요 (planner · designer)
헤더 로고 링크의 **높이 32px는 디자인 시스템 v1.1 §헤더 명세 그대로**다. 즉 이 항목은 구현 실수가 아니라 **REQ-N-006 ②(모든 조작 요소 44px)와 디자인 명세(로고 높이 32px)의 기준 충돌**이다. 두 가지 중 하나가 필요하다.
- ⓐ 로고 링크의 **클릭 영역만** 세로 패딩으로 44px 이상 확보(그래픽 높이는 32px 유지) — 시각 변화 없음, 권고안
- ⓑ REQ-N-006 ②에 로고에 대한 명시적 예외를 추가(요구사항 개정)
푸터 링크 6종은 디자인 명세에 높이 규정이 없으므로 ⓐ와 같은 방식으로 해소 가능하다고 본다.
